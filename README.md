A tiny Python program that writes one toaster error message to `/output/entry.txt`: a single line of at most 120 characters — the error a kitchen toaster shows its owner when something goes wrong, in one deadpan corporate voice held to the end. The message was picked by drafting ten candidates and duelling them pairwise on the bounty judge's own criteria — a real error message from a kitchen toaster and the funniest of its kind, a surprise that arrives from somewhere the obvious toaster puns never go, tightness, one clear appliance voice, and a joke that lands on a single read — then surviving a revision round against three fresh challengers and one tightening of its own wording. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
